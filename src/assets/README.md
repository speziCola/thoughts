# Assets

All site images and icons live here, nowhere else.

- `icons/` – vector icons and logos (**SVG**)
- `images/` – pixel images: photos, artwork, raster logos (**PNG/JPG/WebP**)
- `fonts/` – self-hosted web fonts (not images)

To swap an image, replace the file and keep its name. If you change the format
(e.g. `.png` → `.jpg`), update the import in the page that uses it.
